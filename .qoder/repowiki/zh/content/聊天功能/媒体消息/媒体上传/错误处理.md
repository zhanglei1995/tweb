## 简介
本文档全面记录了上传错误处理机制，详细描述了网络异常处理、文件相关错误处理、服务器端错误响应处理、错误日志记录机制以及不同错误类型的分类处理策略。系统通过多层次的错误检测、自动重试、超时处理和用户友好的提示信息，确保了文件上传过程的稳定性和用户体验。

## 网络异常处理策略

系统实现了完善的网络异常处理机制，包括网络中断检测、自动重试和超时处理。当网络请求失败时，系统会根据错误类型自动执行相应的恢复策略。

```mermaid
flowchart TD
Start([开始上传]) --> CheckNetwork["检查网络连接"]
CheckNetwork --> NetworkOK{"网络正常?"}
NetworkOK --> |是| UploadPart["上传文件分片"]
NetworkOK --> |否| WaitReconnect["等待网络恢复"]
WaitReconnect --> CheckNetwork
UploadPart --> UploadSuccess{"上传成功?"}
UploadSuccess --> |是| NextPart["继续下一个分片"]
UploadSuccess --> |否| CheckErrorType["检查错误类型"]
CheckErrorType --> IsFloodWait{"是否为FLOOD_WAIT?"}
IsFloodWait --> |是| WaitFlood["等待指定时间后重试"]
IsFloodWait --> |否| IsFileMigrate{"是否为FILE_MIGRATE?"}
IsFileMigrate --> |是| ChangeDC["切换到新的DC"]
IsFileMigrate --> |否| IsSessionExpired{"会话是否过期?"}
IsSessionExpired --> |是| Reauthorize["重新授权"]
IsSessionExpired --> |否| OtherError["其他错误处理"]
WaitFlood --> UploadPart
ChangeDC --> UploadPart
Reauthorize --> UploadPart
OtherError --> Fail["上传失败"]
NextPart --> AllPartsUploaded{"所有分片上传完成?"}
AllPartsUploaded --> |否| UploadPart
AllPartsUploaded --> |是| Complete["上传完成"]
```

## 文件相关错误处理

系统对文件相关错误进行了全面的处理，包括格式不支持、大小超限和文件损坏等情况。通过预检查和实时验证，系统能够及时发现并处理各种文件问题。

```mermaid
flowchart TD
Start([文件选择]) --> CheckFormat["检查文件格式"]
CheckFormat --> FormatSupported{"格式支持?"}
FormatSupported --> |否| ShowFormatError["提示格式不支持"]
FormatSupported --> |是| CheckSize["检查文件大小"]
CheckSize --> SizeValid{"大小有效?"}
SizeValid --> |否| ShowSizeError["提示大小超限"]
SizeValid --> |是| CheckIntegrity["检查文件完整性"]
CheckIntegrity --> FileValid{"文件完整?"}
FileValid --> |否| ShowCorruptionError["提示文件损坏"]
FileValid --> |是| PrepareUpload["准备上传"]
PrepareUpload --> UploadProcess["上传处理"]
UploadProcess --> UploadSuccess{"上传成功?"}
UploadSuccess --> |是| Success["上传成功"]
UploadSuccess --> |否| HandleUploadError["处理上传错误"]
HandleUploadError --> RetryOption["提供重试选项"]
ShowFormatError --> UserAction["用户操作"]
ShowSizeError --> UserAction
ShowCorruptionError --> UserAction
RetryOption --> UserAction
UserAction --> End([结束])
```

## 错误日志记录机制

系统实现了完善的错误日志记录机制，便于问题排查和系统优化。通过详细的日志记录，开发人员可以快速定位和解决各种问题。

```mermaid
flowchart TD
Start([错误发生]) --> LogError["记录错误信息"]
LogError --> CheckErrorType["检查错误类型"]
CheckErrorType --> ShouldLog{"需要记录日志?"}
ShouldLog --> |是| FormatLog["格式化日志信息"]
ShouldLog --> |否| SkipLog["跳过日志记录"]
FormatLog --> AddTimestamp["添加时间戳"]
AddTimestamp --> AddPrefix["添加前缀"]
AddPrefix --> AddStackTrace["添加堆栈跟踪"]
AddStackTrace --> WriteToConsole["写入控制台"]
WriteToConsole --> CheckDebugMode{"调试模式?"}
CheckDebugMode --> |是| SaveToFile["保存到文件"]
CheckDebugMode --> |否| EndConsole["仅控制台输出"]
SkipLog --> End([结束])
EndConsole --> End
```

## 错误分类处理策略

系统对不同类型的错误采用了分类处理策略，确保每种错误都能得到适当的处理。错误分为网络错误、文件错误、会话错误和服务器错误等类别。

```mermaid
flowchart TD
Start([错误分类]) --> CheckCategory["检查错误类别"]
CheckCategory --> NetworkError{"网络错误?"}
NetworkError --> |是| HandleNetwork["网络错误处理"]
NetworkError --> |否| FileError{"文件错误?"}
FileError --> |是| HandleFile["文件错误处理"]
FileError --> |否| SessionError{"会话错误?"}
SessionError --> |是| HandleSession["会话错误处理"]
SessionError --> |否| ServerError{"服务器错误?"}
ServerError --> |是| HandleServer["服务器错误处理"]
ServerError --> |否| UnknownError["未知错误处理"]
HandleNetwork --> RetryWithDelay["延迟重试"]
HandleNetwork --> SwitchDC["切换DC"]
HandleNetwork --> CheckConnection["检查网络连接"]
HandleFile --> ValidateFormat["验证文件格式"]
HandleFile --> CheckSize["检查文件大小"]
HandleFile --> VerifyIntegrity["验证文件完整性"]
HandleSession --> Reauthorize["重新授权"]
HandleSession --> Logout["注销用户"]
HandleSession --> RefreshSession["刷新会话"]
HandleServer --> ParseErrorCode["解析错误码"]
HandleServer --> ShowUserFriendly["显示用户友好提示"]
HandleServer --> ReportError["上报错误"]
UnknownError --> DefaultHandle["默认处理"]
DefaultHandle --> LogError["记录错误"]
DefaultHandle --> NotifyUser["通知用户"]
RetryWithDelay --> End
SwitchDC --> End
CheckConnection --> End
ValidateFormat --> End
CheckSize --> End
VerifyIntegrity --> End
Reauthorize --> End
Logout --> End
RefreshSession --> End
ParseErrorCode --> End
ShowUserFriendly --> End
ReportError --> End
LogError --> End
NotifyUser --> End
```

## 用户可操作的恢复路径

系统为用户提供了清晰的可操作恢复路径，当上传失败时，用户可以根据提示采取相应的恢复措施。通过友好的用户界面和明确的指引，降低了用户的操作难度。

```mermaid
sequenceDiagram
participant User as "用户"
participant UI as "用户界面"
participant System as "系统"
participant Server as "服务器"
User->>UI : 选择文件上传
UI->>System : 开始上传
System->>Server : 上传文件分片
Server-->>System : 返回错误
System->>System : 分析错误类型
System->>UI : 生成用户提示
UI->>User : 显示错误信息和恢复选项
alt 网络问题
User->>UI : 确认网络连接
UI->>System : 重新尝试上传
System->>Server : 继续上传
end
alt 文件问题
User->>UI : 选择其他文件
UI->>System : 重新上传
System->>Server : 上传新文件
end
alt 会话问题
User->>UI : 重新登录
UI->>System : 重新授权
System->>Server : 建立新会话
System->>Server : 继续上传
end
Server-->>System : 上传成功
System->>UI : 通知上传完成
UI->>User : 显示成功提示
```
