## 引言
本项目实现了完整的非对称加密体系，包括RSA算法、SRP(Secure Remote Password)协议和Diffie-Hellman密钥交换机制。这些加密技术共同构成了安全通信的基础，确保了用户数据的机密性、完整性和身份验证。系统遵循MTProto协议的安全准则，实现了端到端加密和安全的身份验证流程。

## SRP协议实现

### SRP协议概述
SRP(Secure Remote Password)协议用于实现安全的密码验证，避免了在通信过程中直接传输密码。该协议基于Diffie-Hellman密钥交换原理，结合密码哈希技术，实现了零知识证明的身份验证。

### 密码哈希与验证流程
SRP协议首先对用户密码进行多重哈希处理，生成密码哈希值。这个过程包括SHA-256哈希、PBKDF2密钥派生函数和额外的SHA-256哈希步骤。

```mermaid
flowchart TD
A[用户密码] --> B[SHA-256(client_salt + password + client_salt)]
B --> C[server_salt + hash + server_salt]
C --> D[SHA-256(hash)]
D --> E[PBKDF2(hash, client_salt, 100000)]
E --> F[server_salt + hash + server_salt]
F --> G[SHA-256(hash)]
G --> H[最终密码哈希]
style A fill:#f9f,stroke:#333
style H fill:#bbf,stroke:#333
```

- [srp.ts](file://src/lib/crypto/srp.ts#L17-L28)

### SRP验证流程
SRP验证流程包括客户端和服务器之间的多次交互，通过数学计算验证双方是否拥有相同的密码信息，而无需直接传输密码。

```mermaid
sequenceDiagram
participant 客户端
participant 服务器
客户端->>服务器 : 发送用户名
服务器->>客户端 : 返回salt1, salt2, p, g, srp_B
客户端->>客户端 : 计算密码哈希pw_hash
客户端->>客户端 : 计算x = H(salt1 + pw_hash + salt2)
客户端->>客户端 : 计算v = g^x mod p
客户端->>客户端 : 生成随机数a
客户端->>客户端 : 计算A = g^a mod p
客户端->>服务器 : 发送A
服务器->>服务器 : 计算u = H(A, B)
服务器->>服务器 : 计算S = (A * v^u)^b mod p
服务器->>服务器 : 计算K = H(S)
服务器->>服务器 : 计算M1 = H(H(p) XOR H(g), H(salt1), H(salt2), A, B, K)
服务器->>客户端 : 发送M1
客户端->>客户端 : 验证M1
Note over 客户端,服务器 : SRP协议实现安全的密码验证
```

### 端到端加密会话建立
Diffie-Hellman密钥交换在端到端加密会话建立中发挥核心作用。客户端和服务器各自生成私钥，并交换公钥，最终计算出相同的共享密钥。

```mermaid
sequenceDiagram
participant 客户端
participant 服务器
客户端->>服务器 : 请求DH配置
服务器->>客户端 : 返回p, g参数
客户端->>客户端 : 生成随机私钥a
客户端->>客户端 : 计算公钥g_a = g^a mod p
客户端->>客户端 : 计算g_a的SHA-256哈希
客户端->>服务器 : 发送g_a和哈希
服务器->>服务器 : 生成随机私钥b
服务器->>服务器 : 计算公钥g_b = g^b mod p
服务器->>服务器 : 计算共享密钥S = g_a^b mod p
服务器->>客户端 : 发送g_b
客户端->>客户端 : 计算共享密钥S = g_b^a mod p
客户端->>客户端 : 验证g_b的哈希
客户端->>服务器 : 确认会话建立
Note over 客户端,服务器 : Diffie-Hellman密钥交换建立共享密钥
```

## 公钥基础设施

### 证书验证机制
系统实现了严格的证书验证机制，确保使用的DH参数符合安全标准。验证过程包括检查素数p的值、生成元g的值以及公钥gA的范围。

```mermaid
flowchart TD
A[接收DH参数] --> B{g == 3?}
B --> |否| C[拒绝连接]
B --> |是| D{p == 预定义大素数?}
D --> |否| C
D --> |是| E{1 < gA < p-1?}
E --> |否| C
E --> |是| F{2^(2048-64) < gA < p-2^(2048-64)?}
F --> |否| C
F --> |是| G[接受连接]

style G fill:#9f9,stroke:#333
```
