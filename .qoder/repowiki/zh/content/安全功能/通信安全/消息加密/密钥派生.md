## PBKDF2密钥派生机制

PBKDF2（Password-Based Key Derivation Function 2）是一种基于密码的密钥派生函数，用于从密码生成加密密钥。在本项目中，PBKDF2被用于多种安全场景，包括密码哈希和加密密钥派生。

### PBKDF2实现细节
PBKDF2函数通过多次迭代哈希运算来增强安全性，防止暴力破解攻击。实现中使用了SHA-512作为底层哈希算法，通过多次迭代增加计算成本。

```mermaid
flowchart TD
Start([开始]) --> ImportKey["导入原始密钥材料"]
ImportKey --> DeriveBits["执行PBKDF2派生"]
DeriveBits --> SetParams["设置参数: salt, iterations, hash"]
SetParams --> ApplyHash["应用SHA-512哈希函数"]
ApplyHash --> CheckIterations["检查迭代次数"]
CheckIterations --> |未完成| ApplyHash
CheckIterations --> |完成| ReturnResult["返回派生的密钥位"]
ReturnResult --> End([结束])
```

## SRP协议实现

安全远程密码协议（Secure Remote Password, SRP）是一种安全的认证协议，允许客户端和服务器在不传输密码的情况下进行相互认证。

### SRP认证流程
SRP协议实现了零知识证明认证，确保密码不会在网络上传输。协议使用大素数和模幂运算来建立安全会话。

```mermaid
sequenceDiagram
participant Client as "客户端"
participant Server as "服务器"
Client->>Server : 发送用户名
Server->>Client : 返回盐值和公钥B
Client->>Client : 计算密码哈希
Client->>Client : 生成私钥a
Client->>Client : 计算公钥A
Client->>Server : 发送公钥A
Server->>Server : 验证客户端
Server->>Client : 发送会话密钥验证M1
Client->>Client : 验证服务器
Client->>Server : 发送会话密钥验证M2
Server->>Client : 认证成功
```

### SRP密码哈希计算
SRP协议中的密码哈希计算采用了多层哈希处理，增强了安全性。

```mermaid
flowchart TD
Start([开始]) --> ClientSaltHash["客户端盐+密码+客户端盐"]
ClientSaltHash --> SHA256_1["SHA-256哈希"]
SHA256_1 --> ServerSaltHash["服务器盐+哈希+服务器盐"]
ServerSaltHash --> SHA256_2["SHA-256哈希"]
SHA256_2 --> PBKDF2["PBKDF2派生(100,000次迭代)"]
PBKDF2 --> FinalHash["最终密码哈希"]
FinalHash --> End([返回])
```

## DH密钥交换协议

Diffie-Hellman（DH）密钥交换协议允许双方在不安全的通信渠道上建立共享密钥。

### DH密钥交换流程
DH协议通过数学难题实现安全密钥交换，即使通信被监听也无法推导出共享密钥。

```mermaid
sequenceDiagram
participant Client as "客户端"
participant Server as "服务器"
Server->>Client : 发送大素数p和生成元g
Client->>Client : 生成私钥a
Client->>Client : 计算公钥g^a mod p
Client->>Server : 发送公钥A
Server->>Server : 生成私钥b
Server->>Server : 计算公钥g^b mod p
Server->>Client : 发送公钥B
Client->>Client : 计算共享密钥B^a mod p
Server->>Server : 计算共享密钥A^b mod p
Client->>Server : 验证共享密钥
```
