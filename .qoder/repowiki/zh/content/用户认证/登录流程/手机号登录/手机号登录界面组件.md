## 核心组件

手机号登录界面的核心组件包括手机号输入组件和验证码输入组件。`pageSignIn.ts` 实现了手机号输入界面，包含国际区号选择和号码格式验证功能。`pageAuthCode.ts` 实现了验证码输入界面，包含6位验证码输入框、倒计时显示和重新发送按钮。

## 架构概述

手机号登录流程采用分步验证架构，首先通过手机号验证，然后进行验证码验证。系统通过事件驱动的方式管理状态转换，确保用户体验的流畅性。

```mermaid
sequenceDiagram
participant 用户
participant pageSignIn
participant API
participant pageAuthCode
用户->>pageSignIn : 输入手机号
pageSignIn->>pageSignIn : 实时格式验证
用户->>pageSignIn : 点击下一步
pageSignIn->>API : 发送 auth.sendCode 请求
API-->>pageSignIn : 返回验证码信息
pageSignIn->>pageAuthCode : 导航到验证码页面
用户->>pageAuthCode : 输入验证码
pageAuthCode->>API : 发送 auth.signIn 请求
API-->>pageAuthCode : 返回登录结果
pageAuthCode->>用户 : 显示登录成功或失败
```
