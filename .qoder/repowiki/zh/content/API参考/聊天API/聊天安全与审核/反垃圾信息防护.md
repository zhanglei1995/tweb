## 引言
本系统通过多层次的机制来检测和阻止垃圾信息，包括频率限制、行为模式识别、黑名单机制等。核心组件`appMessagesManager`负责识别垃圾信息，`appChatsManager`执行相应的限制措施，而`bubbles`组件则提供对疑似垃圾信息的视觉提示和用户交互设计。本文档详细说明这些组件的工作原理和配置方法。

## 反垃圾信息检测机制

### 频率限制
系统通过`appMessagesManager`中的`canSendToPeer`方法检查用户是否具有发送消息的权限。该方法会验证用户是否被限制，以及是否满足频道的发送权限。

```mermaid
flowchart TD
Start([开始]) --> CheckPeerRestricted["检查用户是否被限制"]
CheckPeerRestricted --> |是| ReturnFalse["返回 false"]
CheckPeerRestricted --> |否| CheckAction["检查操作权限"]
CheckAction --> CheckChatRights["检查频道权限"]
CheckChatRights --> ReturnResult["返回权限检查结果"]
```

**Diagram sources**
- [appMessagesManager.ts](file://src/lib/appManagers/appMessagesManager.ts#L7846-L7870)

### 行为模式识别
系统通过`isMessageRestricted`函数检测消息是否被限制。该函数检查消息的`restriction_reason`字段，如果存在且被标记为受限，则认为该消息是垃圾信息。

```mermaid
classDiagram
class isMessageRestricted {
+message : Message.message
+return : boolean
}
class isMessageSensitive {
+message : Message
+return : boolean
}
class isRestricted {
+reasons : RestrictionReason[]
+return : boolean
}
isMessageRestricted --> isRestricted : "调用"
isMessageSensitive --> isRestricted : "调用"
```

系统使用`reportSpamMessages`方法将用户报告为垃圾信息发送者。该方法会调用API将指定用户加入黑名单。

## 限制措施执行

### 暂时禁言
`appChatsManager`的`editBanned`方法用于修改用户的禁言权限。通过设置`banned_rights`参数，可以实现暂时禁言或永久禁言。

```mermaid
sequenceDiagram
participant Client as "客户端"
participant AppChatsManager as "AppChatsManager"
participant API as "API"
Client->>AppChatsManager : editBanned(id, participant, bannedRights)
AppChatsManager->>API : invokeApi('channels.editBanned')
API-->>AppChatsManager : 返回更新
AppChatsManager->>AppChatsManager : 生成本地更新
AppChatsManager-->>Client : 完成禁言
```

**Diagram sources**
- [appChatsManager.ts](file://src/lib/appManagers/appChatsManager.ts#L713-L749)

### 移除成员
`kickFromChannel`方法用于将用户从频道中移除。该方法实际上是调用`editBanned`方法，设置`view_messages`权限为`true`来实现移除。

```mermaid
classDiagram
class AppChatsManager {
+editBanned(id, participant, bannedRights)
+kickFromChannel(id, participant)
}
AppChatsManager --> AppChatsManager : "kickFromChannel 调用 editBanned"
```

**Diagram sources**
- [appChatsManager.ts](file://src/lib/appManagers/appChatsManager.ts#L759-L767)

### 慢速模式
`toggleSlowMode`方法用于开启或关闭频道的慢速模式。该模式限制用户发送消息的频率，有效防止垃圾信息刷屏。

```mermaid

MigrateChat --> InvokeAPI["调用 channels.toggleSlowMode API"]
InvokeAPI --> ProcessUpdate["处理更新"]
ProcessUpdate --> End([结束])
```

## 应对新型垃圾信息攻击

### 动态策略调整
系统支持动态调整反垃圾策略。当检测到新型垃圾信息攻击模式时，可以通过更新`restriction_reason`来添加新的限制规则。

```mermaid
flowchart LR
Detection((检测)) --> Analysis["分析攻击模式"]
Analysis --> UpdateRules["更新限制规则"]
UpdateRules --> Deployment["部署新策略"]
Deployment --> Monitoring["监控效果"]
Monitoring --> Feedback["反馈调整"]
```

### 付费消息防护
对于付费消息，系统通过`paidMessagesInterceptor`组件进行额外的防护。该组件会检查用户的星币余额，并在发送前进行确认。

```mermaid
sequenceDiagram
participant User as "用户"
participant Interceptor as "PaidMessagesInterceptor"
participant Payment as "支付系统"
User->>Interceptor : 尝试发送付费消息
Interceptor->>Interceptor : 检查星币余额
Interceptor->>Payment : 请求支付确认
Payment-->>Interceptor : 返回确认结果
Interceptor-->>User : 允许或拒绝发送
```

## 结论
本系统通过综合运用频率限制、行为模式识别、黑名单机制等多种技术手段，构建了一个多层次的反垃圾信息防护体系。`appMessagesManager`负责核心的垃圾信息检测，`appChatsManager`执行具体的限制措施，而`bubbles`组件则提供了直观的视觉提示和用户交互。通过灵活的配置选项和动态的策略调整机制，系统能够有效应对各种已知和新型的垃圾信息攻击。
